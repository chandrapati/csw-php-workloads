# Security

This repository is a field note. It does not contain exploits, proof-of-concept requests, or vulnerable images.

- Do not put API keys, secrets, cluster URLs with credentials, or customer names in issues or pull requests.
- The sample policies are examples. They were not applied to a cluster. Do not post them to a production workspace from this repo.
- Segmentation in the sample reduces unapproved connections. It is not a PHP patch. Update PHP, or install a vendor backport you have confirmed.

Report a documentation error by opening an issue. Do not include a live API secret in the report.
